# Deployment & Operations Implementation Plan (Plan 5)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make the whole Grafin AI platform run with one command: Dockerfiles for backend + pipeline (frontend already has one), a `docker-compose.yml` bringing up Postgres, Redis, backend (migrate+seed+serve), the ETL one-shot, the replay worker, the frontend (nginx proxying `/api` + `/ws`), Prometheus, and Grafana; a bootstrap Makefile; CI workflows; a Terraform skeleton; a security pass; and the C4 reconciliation (refresh the system Context/Container from the now-complete repos).

**Architecture:** Multi-repo build contexts. Backend/frontend build from their own repo. The **pipeline image must build from the `repositories/` root** because it has a uv path dependency on `../grafin-ai-backend` — so its build context spans both repos (a `repositories/.dockerignore` keeps the 450 MB dataset and junk out). Postgres is the source of truth; the backend runs Alembic migrations + seed on start; the ETL one-shot loads the CSVs; the replay worker streams. nginx terminates the SPA and reverse-proxies REST + WebSocket to the backend.

**Tech Stack:** Docker + Docker Compose, nginx, Prometheus, Grafana, GitHub Actions, Terraform (skeleton). Verified via `docker compose config` + image builds (a full `up` additionally needs the dataset mounted).

**Repo ownership note:** the three Dockerfiles live in their service repos (Docker requires the Dockerfile inside its build context); everything else (compose, observability, CI orchestration, Terraform, ops docs) lives in `grafin-ai-deploy`.

### Task 3: Frontend nginx — proxy REST + WebSocket

**Files (in `grafin-ai-dashboard-web`):** `nginx.conf`

- [ ] **Step 1: Replace `grafin-ai-dashboard-web/nginx.conf`**

```nginx
server {
    listen 8080;
    listen [::]:8080;
    server_name _;

    root /usr/share/nginx/html;
    index index.html;

    # REST → backend
    location /api/ {
        proxy_pass http://backend:8000;
        proxy_set_header Host $host;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }

    # WebSocket live feed → backend (upgrade headers)
    location /api/v1/ws/ {
        proxy_pass http://backend:8000;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";
        proxy_set_header Host $host;
        proxy_read_timeout 3600s;
    }

    # security headers
    add_header X-Content-Type-Options nosniff;
    add_header X-Frame-Options DENY;
    add_header Referrer-Policy strict-origin-when-cross-origin;

    location / {
        try_files $uri $uri/ /index.html;
    }
}
```
Note: the more specific `location /api/v1/ws/` must precede `location /api/` for WS upgrade to win (nginx longest-prefix match handles this; keep both).

```yaml
name: grafin-ai

x-db-url: &db_url postgresql+asyncpg://${POSTGRES_USER:-grafin}:${POSTGRES_PASSWORD:-grafin}@postgres:5432/${POSTGRES_DB:-grafin}

services:
  postgres:
    image: postgres:16-alpine
    environment:
      POSTGRES_USER: ${POSTGRES_USER:-grafin}
      POSTGRES_PASSWORD: ${POSTGRES_PASSWORD:-grafin}
      POSTGRES_DB: ${POSTGRES_DB:-grafin}
    healthcheck:
      test: ["CMD-SHELL", "pg_isready -U ${POSTGRES_USER:-grafin}"]
      interval: 5s
      timeout: 3s
      retries: 10
    volumes:
      - pgdata:/var/lib/postgresql/data

  redis:
    image: redis:7-alpine
    healthcheck:
      test: ["CMD", "redis-cli", "ping"]
      interval: 5s
      timeout: 3s
      retries: 10

  backend:
    build: { context: ../grafin-ai-backend }
    environment:
      GRAFIN_DATABASE_URL: *db_url
      GRAFIN_REDIS_URL: redis://redis:6379/0
      GRAFIN_JWT_SECRET: ${GRAFIN_JWT_SECRET:?set a >=32 char secret}
      GRAFIN_ENV: ${GRAFIN_ENV:-production}
    depends_on:
      postgres: { condition: service_healthy }
      redis: { condition: service_healthy }
    ports: ["8000:8000"]

  etl:
    build: { context: .., dockerfile: grafin-ai-pipeline/Dockerfile }
    command: ["uv", "run", "grafin-etl"]
    environment:
      GRAFIN_DATABASE_URL: *db_url
      GRAFIN_DATA_DIR: /data
    volumes:
      - ${GRAFIN_DATA_HOST_DIR:-../grafin-ai-data/HI-Small}:/data:ro
    depends_on:
      backend: { condition: service_started }
      postgres: { condition: service_healthy }
    restart: "no"

  replay:
    build: { context: .., dockerfile: grafin-ai-pipeline/Dockerfile }
    command: ["uv", "run", "grafin-replay"]
    environment:
      GRAFIN_DATABASE_URL: *db_url
      GRAFIN_REDIS_URL: redis://redis:6379/0
      GRAFIN_RESET_CLOCK: "true"
    depends_on:
      etl: { condition: service_completed_successfully }
      redis: { condition: service_healthy }
    restart: unless-stopped

  frontend:
    build: { context: ../grafin-ai-dashboard-web }
    depends_on: [backend]
    ports: ["8080:8080"]

  prometheus:
    image: prom/prometheus:latest
    volumes:
      - ./observability/prometheus.yml:/etc/prometheus/prometheus.yml:ro
    ports: ["9090:9090"]

  grafana:
    image: grafana/grafana:latest
    environment:
      GF_AUTH_ANONYMOUS_ENABLED: "true"
      GF_AUTH_ANONYMOUS_ORG_ROLE: Viewer
    volumes:
      - ./observability/grafana/provisioning:/etc/grafana/provisioning:ro
    depends_on: [prometheus]
    ports: ["3000:3000"]

volumes:
  pgdata:
```

	@test -f .env || (echo "copy .env.example to .env and set GRAFIN_JWT_SECRET" && exit 1)

	docker compose down

	docker compose logs -f --tail=100

- [ ] **Step 2: `grafin-ai-deploy/README.md`** — document the one-command bring-up, including the `repositories/.dockerignore` requirement and the boot order:

````markdown
# Grafin AI — Deploy

One-command local stack: Postgres, Redis, backend (migrate+seed+serve), ETL (one-shot
CSV load), replay worker, frontend (nginx), Prometheus, Grafana.

## Prerequisites
- Docker + Docker Compose
- The dataset at `../grafin-ai-data/HI-Small/` (set `GRAFIN_DATA_HOST_DIR` otherwise)
- A `repositories/.dockerignore` at the workspace root (the pipeline build context).
  If missing, create it with: `.venv`, `node_modules`, `.git`, `grafin-ai-data`, `build`, `dist`.

## Run
```bash
cp .env.example .env
make seed-secret   # paste into GRAFIN_JWT_SECRET in .env
make up
```
Boot order is enforced by health checks + `depends_on`:
postgres/redis → backend (runs `alembic upgrade head` + seeds admin/sim_state) →
etl (loads ~5M transactions, runs once) → replay (streams scored events to Redis).

## URLs
- Dashboard: http://localhost:8080  (login: `admin@grafin.local` / `admin`)
- API + docs: http://localhost:8000/docs
- Prometheus: http://localhost:9090
- Grafana: http://localhost:3000

## Notes
- First run loads the full dataset — the `etl` service can take minutes; `replay` waits
  for it (`service_completed_successfully`).
- Change `admin@grafin.local`'s password before any non-demo use.
````
